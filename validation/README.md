# Validation

Mục tiêu: cho >=5 người ngoài nhóm dùng prototype và ghi lại hành vi thật.

## Cách Test

1. Giao task thật: "Hãy dùng công cụ này để tìm lại [nguồn/tài nguyên] trên Discord."
2. Im lặng quan sát, không gợi ý.
3. Ghi thời gian, kết quả, nơi bị kẹt.
4. Hỏi 3 câu:
   - Điều gì khó hiểu hoặc khó chịu nhất?
   - Kết quả này bạn có tin không, vì sao?
   - Bạn có dùng thật không, vì sao/vì sao chưa?
5. Ghi quote nguyên văn.

## Đầu Ra

- `user_test_log.csv`: log từng người.
- `summary.md`: tổng hợp pattern.
- `changes_from_feedback.md`: thay đổi từ feedback hoặc lý do giữ nguyên.
