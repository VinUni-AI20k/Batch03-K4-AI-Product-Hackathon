# StudyPulse FE

Frontend prototype dùng Vite + React và Tailwind CSS CDN. Toàn bộ dữ liệu và tương tác hiện là mock để phục vụ demo khi backend chưa sẵn sàng.

## Chạy local

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
```

## Luồng demo

- Lọc mail quan trọng, Discord, lịch hôm nay và deadline tuần.
- Gửi câu hỏi cho trợ lý; thử yêu cầu ngoài phạm vi như “viết hộ bài luận”.
- Chỉnh sửa mốc thời gian AI trích xuất.
- Đánh dấu kết quả sai để chuyển sang bước TA kiểm tra.
- Xác nhận thêm sự kiện vào Google Calendar.
- Mở “Quản lý kết nối” và kết nối Gmail.

Gmail, Discord, Outlook và Google Calendar trong giao diện đều là mock.
