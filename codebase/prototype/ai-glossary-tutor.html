VLearn · Lecture 04
Excerpt — "Building LLM Applications"

Why do chatbots need external knowledge?

A large language model (LLM) only knows what it learned during training. When you ask about internal documents or recent events, the model may hallucinate — producing answers that sound fluent and confident, but are actually wrong.

Retrieval-Augmented Generation (RAG) solves this problem by letting the system retrieve relevant information first, and only then generate the answer. Documents are split into small chunks, converted into embeddings, and stored in a vector database so the system can run semantic search over them.

With this approach, there is no need for expensive fine-tuning every time new documents arrive. You simply update the knowledge base, and the model always answers from the latest source — with citations included.
