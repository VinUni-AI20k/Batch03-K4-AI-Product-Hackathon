# Tóm tắt bài học

## Quy trình
- [ ] 1. `get_lesson` lấy toàn văn bài.
- [ ] 2. Viết theo đúng cấu trúc:
      **Ý chính** (5–8 bullet) → **Khái niệm cần nhớ** (mỗi khái niệm 1 câu, dạng [[wikilink]]) → **Câu hỏi tự kiểm tra** (3 câu mở).
- [ ] 3. Mỗi ý chính giữ trích nguồn slide/timestamp gốc.

## Lưu ý
- Bài dài → ưu tiên phần "Khái niệm chính" trong ghi chú.
- Không thêm kiến thức ngoài tài liệu.
