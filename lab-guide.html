Repository audit

Biết chỗ thiếu trước khi làm

Kết luận dựa trên commit được audit. Test và mã chạy không tồn tại; vì vậy các lệnh bên dưới là kiểm tra contract, không phải automated test.

Setup

Chuẩn bị repo có thể kiểm chứng

Clone đúng nguồn, kiểm branch/commit, rồi đọc example trước worksheet. Không cần cài package, API key hay dịch vụ bên ngoài.

Team model

4 vai trò, một file tích hợp

Repo quy định nhóm 3–4 người. Với nhóm 3, gộp vai trò Evidence và Workflow; không để nhiều người cùng sửa group-report.md.

Step by step

8 phase theo critical path

Phase cá nhân chạy song song; phase hội tụ và tích hợp chạy tuần tự. Mỗi checkpoint phải pass trước khi chuyển phase.

Artifact contract

File hiện hữu và file mới

Ba report đã tồn tại trong starter repo. Guide không yêu cầu tạo file mới; ảnh/PDF/note chỉ là artifact phụ nếu nhóm thực sự cần.

Validation

Chứng minh bài nộp đủ contract

Không có test runner trong repo. Dùng kiểm tra file, từ khóa, diff và review theo rubric; mọi claim research vẫn phải mở nguồn để xác minh.

Definition of Done

Chốt bài trước khi nộp

Checklist này lưu trên trình duyệt của bạn. Nó không sửa repo và không thay thế việc đọc diff cuối cùng.
