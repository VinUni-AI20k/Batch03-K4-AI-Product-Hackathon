Kiến trúc & pipeline

Tài liệu của bạn → kho tri thức có trích nguồn.

1 · Nạp

Slide · Video · Ghi âm

Docling (PDF/PPTX+OCR) · PhoWhisper (ASR tiếng Việt) · gửi thẳng qua chat.

2 · Cấu trúc hoá

Lớp knowledge

LLM tách khái niệm, wikilink → vault markdown kiểu Obsidian, git-versioned.

3 · Index

Voyage + Chroma

Embedding ngữ cảnh chất lượng tiếng Việt cao → RAG truy hồi chính xác.

✓ Xác nhận trước khi nạp ↻ Phát hiện update (thay/giữ/bỏ) ⚡ Incremental — mỗi lần 1 git commit

Một gateway chạy cả Telegram + Discord + scheduler; một dashboard web quản trị. Vault markdown là nguồn sự thật, index chỉ là phái sinh.
