# Demo Pull Request

Đây là thay đổi mẫu để nhóm thực hành Git workflow.

Nếu bạn đang đọc file này trên nhánh `main`, Pull Request demo đã được merge thành công.

## Nội dung kiểm tra

- Branch nguồn: `docs/demo-merge`
- Branch đích: `main`
- Thay đổi: thêm một file Markdown, không ảnh hưởng đến dữ liệu hay prototype
