## What changed after the first Socratic run

- A deterministic pre-check blocks direct requests for the answer, answer
  letter, or confirmation of an option before the request reaches the model.
- The response guardrail blocks only explicit answer-option leakage; it no
  longer rejects a legitimate conceptual explanation such as “RAG viết tắt là
  gì?”.
- The evaluator now measures `blocked` (the policy decision) separately from
  `is_safe` (whether the returned text leaks an answer).

## Remaining quiz-generation failures

`N02`, `N03`, and `R02` returned `INSUFFICIENT_EVIDENCE` rather than `OK`.
Each supplies only three short source chunks while requesting fifteen distinct,
fair questions with no outside knowledge or repetition. The agent correctly
refused to invent questions. The product uses five questions for this
reinforcement-quiz scenario; the existing golden set should be revised to
either request five questions for these cases or accept `INSUFFICIENT_EVIDENCE`
as the expected safe outcome.
